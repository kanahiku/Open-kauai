# Maintenance Tasks

Recurring tasks to keep the site healthy after launch.

---

## Monthly

### Dependabot Updates
**What**: Review and merge Dependabot updates. Check the site still builds and works.
**Tool**: GitHub
**Owner**: Developer

### Renewals Check
**What**: Track domain expiry dates (client owned) and our Vercel, Sanity, and Resend plans.
**Tool**: 1Password / tracker
**Owner**: Account Manager

### SEO Health Check
**What**: Check GSC for errors and indexing. Rerun `npm run seo:check` and `npm run links:check`.
**Tool**: Google Search Console, CLI
**Owner**: Developer

---

## Quarterly / After Big Changes

### Security Scan
**What**: Rerun the Strix scan.
**Tool**: Strix
**When**: After big changes, and every few months
**Owner**: Developer

---

## Every 6 Months

### Backup Restore Test
**What**: Restore a Sanity backup to the staging dataset and check it worked.
**Tool**: Sanity
**Owner**: Developer

---

## Yearly

### Alerts Review
**What**: Decide who gets HetrixTools and Vercel alerts and how fast we respond.
**Tool**: HetrixTools, Vercel
**Owner**: Team Lead

---

## Per Request

### Change Requests
**What**: How clients send changes and how fast we turn them around.
**Tool**: Slack / Email
**Owner**: Account Manager
